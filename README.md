# BARK & MEOW – Pet Shop Management System

## Project Description
BARK & MEOW is a simple Pet Shop Management System developed using Python and Django. It helps manage products, customers, and pet details.

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## Features
- Product Management – Add, view, edit, and delete products.
- Product Image Upload
- Customer Management – Add, view, edit, and delete customer details.
- Pet Management – Add, view, edit, and delete pet details.
- Admin Panel
- Simple and user-friendly interface

## How to Run the Project
1. Clone or download this repository.
2. Install Django and Pillow.
3. Run database migrations:
   `py manage.py migrate`
4. Start the development server:
   `py manage.py runserver`
5. Open `http://127.0.0.1:8000/` in your browser.
